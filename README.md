# ip-02-three-game · 作业二：互动艺术与电子媒介（Three.js）

朱栩汕 · 数字媒体艺术 · 大二 · 《互动编程》

一个能玩起来的 3D 躲避小游戏，打开网页就能玩。

在线游玩（GitHub Pages）：https://sleepy677.github.io/ip-02-three-game/

## 玩法

- **WASD / 方向键** 移动，躲避四面八方飞来的红色能量球
- 撑过 **180 秒** 即胜利；被击中扣 1 条命，共 3 条命，受击后 1.2 秒无敌闪烁
- 随机掉落三种增益（每 8~14 秒一个，9 秒后消失）：
  - 🟢 **生命晶体**：生命 +1（上限 4 格）
  - 🟡 **护盾核心**：获得护盾，抵挡一次伤害
  - 🔵 **时间碎片**：剩余时间 +15 秒

## 技术要点

- Three.js r128（本地引入，603KB，离线可运行）
- CanvasTexture 辉光贴图 + AdditiveBlending 实现光晕、拖尾、爆炸粒子（对象池复用）
- 环绕星尘带、四角信标柱、玩家 banking 倾斜、相机受击震动、ACES 色调映射
- 玻璃拟态 HUD、时间进度条、最后 10 秒红色告警

## 运行

直接打开 `index.html` 即可，无需构建、无外部依赖。
